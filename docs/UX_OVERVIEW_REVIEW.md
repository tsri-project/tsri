# ปรับหน้าภาพรวมโครงการสำหรับทีมวิจัยและ สกสว.

งานเกี่ยวข้องกับ WS01 การบริหารและควบคุมโครงการ สถานะเสนอ: INTERNAL_REVIEW

## พฤติกรรมที่เปลี่ยน

- หน้า `/dashboard` เปิดด้วยคำอธิบายโครงการ สรุปสถานะ ทางลัด และความก้าวหน้าตาม TOR
- ผู้ใช้เลือกมุมมองภาพรวมสำหรับ สกสว. หรือรายการงานทีมวิจัย โดยการเลือกมุมมองไม่มีผลต่อสิทธิ์เข้าถึง
- เมนูภาษาไทยจัดเป็นการติดตามโครงการ ข้อมูลและงานวิจัย และการประสานงาน ใช้รายการเดียวกันทั้ง Sidebar และเมนูมือถือ
- ลิงก์งานส่งพารามิเตอร์เพื่อกรองงานตามสายงานและรหัสงาน ลิงก์เอกสารเปิดรายละเอียดฉบับของรายการที่เลือก
- หน้าภาพรวมแจ้งชัดว่าตัวเลข สถานะ และวันส่งงานมาจากข้อมูลตัวอย่าง ไม่ใช่ทะเบียนที่รับรองแล้ว
- ปรับขนาดตัวอักษร เป้าหมายการกด เมนูมือถือ พื้นที่ขอบล่าง และการแสดง focus สำหรับคีย์บอร์ด
- แก้ TypeScript เดิม: import DocumentPrefix, ใช้สถานะ DONE ในรายการงาน และแสดงสถานะ CANCELLED ของการประชุมอย่างถูกต้อง

## การตรวจสอบ

- `npm run typecheck`: ผ่าน
- `npm run build`: ผ่าน โดยใช้ URL/คีย์ placeholder สำหรับการตรวจ build เท่านั้น ไม่ใช่การเชื่อมต่อฐานข้อมูลจริง
- `node scripts/test-build-guards.mjs`: ผ่านทั้ง 3 กรณี
- `git diff --check`: ผ่าน
- ยังไม่ได้ทดสอบภาพและ workflow ในเบราว์เซอร์ เนื่องจาก runtime นี้ไม่มี Chromium executable

## ตรวจรับก่อนเผยแพร่

1. ตรวจหน้า dashboard บนมือถือ 360px/390px และคอมพิวเตอร์ 1280px/1440px ว่าข้อความอ่านได้และไม่มีการเลื่อนแนวนอน
2. สลับมุมมองทีมวิจัย เปิดงาน ตรวจว่าตัวกรองแสดงงานที่เลือก
3. ค้นหาเอกสารใน dashboard เปิดรายการ ตรวจว่า modal แสดงเอกสารตรงกันและปิดได้
4. ตรวจเมนูมือถือ คีย์บอร์ด การค้นหาส่วนกลาง และการออกจากระบบ
5. ตรวจด้วยบัญชีทีมวิจัยและผู้ติดตามโครงการจริง โดยใช้ staging ที่อนุญาต ไม่ใช้ฐาน production ใน local dev

## ประเด็นข้อมูลที่ต้องให้ PM ยืนยัน

ข้อมูลใน `mock-data.ts` ยังมีโครงสร้างสายงาน วันที่ และสถานะที่ต้องเทียบทะเบียนกลาง งานนี้ไม่ได้รับรองหรือแก้เนื้อหางานวิจัย ต้องเชื่อมแหล่งข้อมูลที่ตรวจสอบแล้วก่อนใช้หน้าภาพรวมรายงานผลจริงต่อ สกสว.

ข้อเสนอสำหรับทะเบียนควบคุมโครงการ: บันทึกงานปรับ UX/UI ใน WS01 พร้อมลิงก์ PR และผลตรวจ จากนั้นมอบหมายการตรวจรับการใช้งานและการเชื่อมข้อมูลจริงให้ผู้รับผิดชอบ ข้อเสนอนี้ยังไม่ใช่การอนุมัติหรือการเลื่อน Gate
