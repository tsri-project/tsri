### INTELLIGENT

### EVIDENCE-BASED

### DATA-DRIVEN

# 08 — VISUAL HIERARCHY

MAIN MESSAGE

### LEVEL 2
SUPPORTING MESSAGE

### LEVEL 3
EVIDENCE / DATA

# 09 — WHITE SPACE

White Space เป็นส่วนหนึ่งของ Design System

ไม่ใช่พื้นที่ว่างที่ต้องเติมให้เต็ม

ใช้เพื่อ:

- แยกกลุ่มข้อมูล
- สร้าง Focus
- เพิ่มความอ่านง่าย
- สร้างความรู้สึก Premium
- ลด Cognitive Load

หลัก:

> ถ้าข้อมูลยังอ่านยาก อย่าเพิ่ม Graphic ให้ลองเพิ่ม White Space ก่อน

# 35 — SOURCE DESIGN

งาน Research / Legal / Policy ต้องมี Source ที่อ่านง่าย

รูปแบบ:

**Source: [Document]**

**Source: [Law / Section / Regulation]**

หากยังไม่ยืนยัน:

**Source: NEED VERIFICATION**

Source ต้องมี Visual Weight ต่ำกว่า Main Message

แต่ยังอ่านได้

# 40 — DESIGN DECISION

ก่อนเลือก Visual ให้ถาม:

1. Main Message คืออะไร?
2. Audience คือใคร?
3. Information เป็นประเภทใด?
4. ต้องการให้ผู้ชม “เข้าใจ / เปรียบเทียบ / ตัดสินใจ / ลงมือทำ”?
5. Visual Model ใดเหมาะที่สุด?
6. Evidence อยู่ตรงไหน?
7. Source อยู่ตรงไหน?
8. Visual ช่วยให้เข้าใจเร็วขึ้นหรือไม่?

หาก Graphic ไม่ช่วยตอบคำถามเหล่านี้:

**ตัดออก**
