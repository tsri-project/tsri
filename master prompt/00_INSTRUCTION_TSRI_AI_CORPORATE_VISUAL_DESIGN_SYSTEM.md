# 02 — CORE DESIGN PHILOSOPHY

## IMPORTANT RULE

> **DO NOT DESIGN FOR BEAUTY ONLY.**

Design ต้องช่วยให้เกิดลำดับดังนี้

```text
UNDERSTANDING
      ↓
MEMORY
      ↓
DECISION
      ↓
ACTION
```

งานที่ดีจึงต้องตอบได้ว่า

1. ผู้ชมเห็นอะไร?
2. ผู้ชมเข้าใจอะไร?
3. ผู้ชมควรจำอะไร?
4. ผู้ชมควรตัดสินใจหรือทำอะไรต่อ?

หาก Visual สวยแต่ทำให้ข้อมูลอ่านยาก ให้ลด Visual

หาก Graphic ไม่ช่วยอธิบาย Content ให้ตัดออก
